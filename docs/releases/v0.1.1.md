## Highlights

### Design on the current Starlight

The preview now runs Starlight 0.42.6, built with Astro 7.3.8. Your exports name 0.42.6 as their target. The controls, the presets and the Export dialog work exactly as they did in 0.1.0.

> **Under the hood:** Starlight 0.42.5 and 0.42.6 changed one thing in their stylesheets: icons no longer get cut off when you pinch-zoom in Firefox. No selector that the studio styles moved. Apart from the line that names the version, every export is byte-identical to the one 0.1.0 made.

## Upgrading

- **This release targets Starlight 0.42.6 and Astro 7.3.8.** A theme you exported from 0.1.0 still applies to any Starlight 0.42 site, so you do not need to export it again. `APPLY-THEME.md` from either release stops your agent only when your site's Starlight minor version is not 0.42.
- **Exports changed only in the version they name.** The header of `theme.css` and the target line of `APPLY-THEME.md` now say 0.42.6. Export again only if you want your files to name the newer version.
- **Your saved themes still open.** Themes saved in your browser, share links and imported settings files load as before.

## Known limits

- **It is built for Starlight 0.42.6.** Starlight is pre-1.0, so a later release can change markup that some styles rely on. `APPLY-THEME.md` names the version it was built for and tells your agent to stop on a mismatch.
- **Some settings only take effect at build time.** Syntax-highlighting themes and a few page options cannot change live. The preview approximates them, and `APPLY-THEME.md` lists the config changes to make.
- **The PNG screenshot is drawn in the browser.** A full page of a long document can take several seconds, and a few effects such as `backdrop-filter` may be missing. For a pixel-exact image, use your browser's own screenshot tool.
- **Safari itself is untested.** The WebKit tests run in Playwright's build of the engine on Windows, not in Apple's Safari.
