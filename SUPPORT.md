# Getting help

Starlight Visual Customizer is a small project. Each kind of request has its own place, so it
reaches the right people and stays findable for the next person with the same question.

| You want to | Go to |
|---|---|
| Ask how to use the studio or apply a theme | [Discussions, Q&A](https://github.com/prisant-labs/starlight-visual-customizer/discussions/categories/q-a) |
| Suggest an idea | [Discussions, Ideas](https://github.com/prisant-labs/starlight-visual-customizer/discussions/categories/ideas) |
| Show a theme you made | [Discussions, Show and tell](https://github.com/prisant-labs/starlight-visual-customizer/discussions/categories/show-and-tell) |
| Report a bug | [The bug form under Issues](https://github.com/prisant-labs/starlight-visual-customizer/issues/new/choose) |
| Report an accessibility barrier | The same bug form, as [`ACCESSIBILITY.md`](ACCESSIBILITY.md) describes |
| Report a security problem | A private report, as [`SECURITY.md`](SECURITY.md) describes. Please do not open a public issue. |
| Report a problem in Starlight itself | [withastro/starlight](https://github.com/withastro/starlight/issues) |

## Before you ask

These documents answer the most common questions:

- **Applying a theme:** the `APPLY-THEME.md` file in your export walks through every step. The
  README's ["How export works"](README.md#how-export-works) section summarizes them, and
  [`docs/export-format.md`](docs/export-format.md) describes each exported file.
- **A control or a part of the studio:** [`docs/studio.md`](docs/studio.md).
- **Running the app yourself:** [`docs/development.md`](docs/development.md).

## Make it easy to help you

A share link reproduces your exact theme and page. In the studio, open **Export** and choose
**Copy share link**, then paste the link into your question or bug report. Please also name your
browser, and the Starlight version of your own site if the question is about applying a theme.

## What to expect

A reply can take a few days. An answered question in Discussions also helps the next person who
searches for the same answer.
